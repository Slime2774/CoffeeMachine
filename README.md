# Coffee Vending Machine Network (WPF)

Десктопное приложение на C# / WPF, имитирующее работу сети кофейных автоматов самообслуживания[cite: 3, 4]. Каждый автомат работает независимо: имеет собственное меню, запасы ингредиентов, кассу, звуковое сопровождение и панель администратора.

---

## Основные возможности

* **Управление сетью автоматов:**
  * Динамическое добавление новых кофейных автоматов на главный экран (`+ Добавить автомат`) с автоматической прокруткой к созданному экземпляру[cite: 3, 4].
  * Независимая конфигурация меню для каждого автомата через отдельные JSON-файлы (`menu_machine_1.json`, `menu_machine_2.json` и т. д.).
* **Клиентский интерфейс и покупка:**
  * **Анимированная заставка (Screen Saver):** автоматически запускается при простое и скрывается при касании экрана.
  * **Интерактивное меню:** отображение карточек напитков с иконками и базовой стоимостью.
  * **Гибкая кастомизация напитка:** выбор объёма стакана, крепости (`Стандарт`, `+1 шот`, `+2 шота`), количества сахара (`0–3` ложки), сиропов (`Карамель`, `Ваниль`, `Лесной орех`) и топпингов (`Корица`, `Маршмеллоу`) с автоматическим пересчётом итоговой цены.
  * **Система оплаты:** поддержка бесконтактной оплаты картой (с имитацией задержки банковского терминала) и приёма наличных купюрами номиналом `50`, `100` и `500 ₽` с расчётом сдачи[cite: 7, 8].
  * **Визуализация процесса приготовления:** анимация заполнения стаканчика напитком, шкала прогресса, обновление визуальной стопки стаканов, звуковые эффекты (`beep.wav`, `coin.wav`, `brew.wav`) и интерактивная выдача сдачи монетами[cite: 7, 8].
* **Панель администратора:**
  * Защищённый вход по паролю (пароль по умолчанию: `admin`)[cite: 7, 8].
  * **Мониторинг и пополнение запасов:** отслеживание остатков кофейных зёрен, воды, молока, сахара, сиропа и стаканчиков с возможностью пополнения в один клик[cite: 7, 8].
  * **Редактор меню:** добавление, редактирование и удаление позиций меню прямо в интерфейсе с сохранением изменений в JSON[cite: 7, 8].

## Структура проекта

```text
CoffeeVendingMachine/
├── Models/
│   ├── CoffeeDrink.cs          # Модель кофейного напитка (наследуется от Drink)
│   ├── Drink.cs                # Базовая модель напитка
│   ├── Config.cs               # Модель настроек цен и размеров стаканов
│   └── Inventory.cs            # Модель учета ингредиентов и расходников
├── Services/
│   └── CoffeeLoader.cs         # Загрузка конфигурации и меню из JSON
├── Data/
│   └── config.json             # Глобальные настройки цен (сиропы, топпинги, объемы)
├── Sounds/
│   ├── beep.wav                # Звук оплаты картой
│   ├── coin.wav                # Звук монет / сдачи
│   └── brew.wav                # Звук приготовления кофе
├── MainWindow.xaml(.cs)        # Главное окно управления сетью автоматов
├── CoffeeMachineView.xaml(.cs) # Основной контрол автомата (6 слоев интерфейса + логика)
├── CustomizationWindow.xaml(.cs) # Окно настройки напитка
└── PaymentWindow.xaml(.cs)     # Окно оплаты
