# Coffee Vending Machine Network (WPF)

Десктопное приложение на **C# / .NET 10 (WPF)**, моделирующее работу сети кофейных автоматов самообслуживания. Каждый автомат в сети является независимым модулем со своим ассортиментом напитков, контролем расхода ингредиентов, кассовым узлом, звуковым сопровождением и защищённой панелью администратора[cite: 3, 4, 7, 8, 16].

## Ключевые возможности

### 1. Управление сетью автоматов
- **Масштабирование в реальном времени:** кнопка `+ Добавить автомат` на верхней панели создаёт новый экземпляр `CoffeeMachineView` с уникальным идентификатором (`machine_1`, `machine_2` и т. д.) и автоматически прокручивает ленту к нему[cite: 3, 4].
- **Изолированное состояние:** каждый автомат ведёт собственный учёт остатков, сдачу, прогресс приготовления и сохраняет меню в отдельный JSON-файл (`menu_machine_{id}.json`)[cite: 4, 8].

### 2. Клиентский интерфейс (6 состояний экрана)
Центральный дисплей автомата построен на переключении 6 независимых слоёв интерфейса:
- **Режим ожидания (Screen Saver):** анимированная заставка с пульсирующей иконкой, которая автоматически активируется при бездействии пользователя и отключается по клику[cite: 7, 8].
- **Витрина напитков (Menu):** сетка карточек с иконкой, названием и базовой ценой напитка[cite: 7].
- **Конструктор напитка (Customization):**
  - Выбор объёма стакана (подгружается из `config.json`)[cite: 2, 8].
  - Настройка крепости: *Стандарт* (1 шот), *+1 шот*, *+2 шота*[cite: 7].
  - Дозировка сахара: *Без сахара*, *1*, *2* или *3 ложки*[cite: 7].
  - Добавки: сиропы (*Карамель*, *Ваниль*, *Лесной орех*) и топпинги (*Корица*, *Маршмеллоу*)[cite: 7].
  - Динамический пересчёт итоговой стоимости при изменении любого параметра[cite: 2, 8].
- **Платёжный терминал (Payment):**
  - **Безналичная оплата:** имитация работы банковского терминала с задержкой обработки (`1.5 сек`) и звуковым подтверждением (`beep.wav`)[cite: 6, 8].
  - **Наличный расчёт:** приём купюр номиналом `50`, `100` и `500 ₽` с отображением внесённой суммы и автоматическим расчётом сдачи[cite: 5, 7, 8].
- **Визуализация приготовления и выдачи:**
  - Анимация заполнения стаканчика в шахте выдачи и шкала прогресса (`ProgressBar`) со звуком кофемашины (`brew.wav`)[cite: 7, 8].
  - Автоматическое уменьшение визуальной стопки стаканчиков на правой панели[cite: 7, 8].
  - Интерактивный лоток сдачи: при оплате наличными с избытком сдача разбивается на монеты и выдаётся в отдельной ячейке со звуком (`coin.wav`)[cite: 7, 8].

### 3. Панель администратора
- Доступ к настройкам защищён паролем (по умолчанию: `admin`)[cite: 7, 8].
- **Вкладка «Запасы»:** визуальные индикаторы остатков (кофе в граммах, вода и молоко в миллилитрах, сахар в граммах, сироп в миллилитрах, количество стаканчиков) и кнопка **«Пополнить всё»** для мгновенного восстановления максимальных объёмов[cite: 7, 8].
- **Вкладка «Меню»:** встроенная таблица (`DataGrid`) для добавления новых напитков, редактирования названий, цен и иконок, удаления позиций и сохранения изменений в JSON[cite: 7, 8].

│   │   └── CoffeeLoader.cs             # Сервис десериализации config.json и menu.json
│   ├── Data/
│   │   ├── config.json                 # Базовые настройки цен и объёмов
│   │   └── menu.json                   # Шаблонное меню напитков

│   │   ├── beep.wav                    # Звук терминала при оплате картой

│   │   └── brew.wav                    # Звук приготовления напитка
│   ├── MainWindow.xaml(.cs)            # Главное окно сети автоматов
│   ├── CoffeeMachineView.xaml(.cs)     # Основной UserControl автомата и вся бизнес-логика
│   ├── CustomizationWindow.xaml(.cs)   # Окно настройки напитка
│   └── PaymentWindow.xaml(.cs)         # Окно оплаты

    ├── CoffeeCalculatorTests.cs        # Тесты расчёта цен, расхода ингредиентов и сдачи
    └── CoffeeLoaderTests.cs            # Тесты десериализации JSON-конфигураций и меню

## Механика расчётов и расхода ингредиентов

### Формула стоимости заказа
$$\text{Итого} = \text{BasePrice} + \text{SizeExtraPrice} + (\text{ExtraShots} \times \text{ExtraEspressoShotPrice}) + (\text{SyrupsCount} \times \text{SyrupPrice}) + (\text{ToppingsCount} \times \text{ToppingPrice})$$

### Расход ресурсов на одну порцию
- **Стаканчики:** `1 шт.`
- **Вода и молоко:** по `50%` от выбранного объёма стакана (`Volume / 2` мл воды и `Volume / 2` мл молока)
- **Кофейные зёрна:** `10 г` на базовый шот + `10 г` за каждый дополнительный шот
- **Сахар:** `5 г` за каждую выбранную ложку (`0`, `5`, `10` или `15 г`)
- **Сироп:** `20 мл` за каждый выбранный вид сиропа[cite: 8]

### Алгоритм выдачи сдачи
При оплате наличными сдача распределяется максимум на **5 монет** равного номинала (остаток от целочисленного деления добавляется к последней монете). Если сумма сдачи меньше `5 ₽`, выдаётся соответствующее количество монет номиналом `1 ₽`[cite: 8].

## Конфигурация и хранение данных

### Глобальный конфиг (`Data/config.json`)
Отвечает за ценообразование добавок и доступные объёмы стаканов[cite: 8, 9]:

```json
{
  "SyrupPrice": 30,
  "ToppingPrice": 25,
  "ExtraEspressoShotPrice": 40,
  "CupSizes": [
    { "Name": "Маленький", "Volume": 200, "ExtraPrice": 0 },
    { "Name": "Средний", "Volume": 300, "ExtraPrice": 20 },
    { "Name": "Большой", "Volume": 400, "ExtraPrice": 40 }
  ]
}
```

### Меню автомата (`menu_machine_{id}.json`)
При первом запуске каждого автомата файл создаётся автоматически в директории сборки. Пример структуры[cite: 8]:

```json
[
  {
    "type": "CoffeeDrink",
    "name": "Капучино",
    "basePrice": 150,
    "icon": "☕",
    "coffeeType": "Arabica"
  }
]
```

## Требования и запуск

- **ОС:** Windows 10 / 11
- **SDK:** .NET 10.0 (`net10.0-windows`)[cite: 15, 16]
- **IDE:** Visual Studio 2022 / 2026 или VS Code с C# Dev Kit

### Запуск из терминала
```bash
git clone [https://github.com/Slime2774/CoffeeMachine.git](https://github.com/Slime2774/CoffeeMachine.git)
cd CoffeeMachine
dotnet run --project CoffeeVendingMachine/CoffeeVendingMachine.csproj
```

## Тестирование и CI/CD

В репозитории настроен пайплайн **GitHub Actions** (`.NET WPF CI/CD / build-and-test`), который автоматически собирает решение в конфигурации `Release` и запускает модульные тесты при каждом `push`[cite: 11].

Покрытие тестами (`CoffeeVendingMachine.Tests`):
- Расчёт итоговой цены с учётом объёма, шотов эспрессо и сиропов[cite: 12].
- Списание ингредиентов и расходников при сложных заказах[cite: 12].
- Проверка блокировки приготовления при нехватке ресурсов[cite: 12].
- Корректность разбивки сдачи на монеты для крупных и малых сумм[cite: 12].
- Десериализация файлов `config.json` и `menu.json`[cite: 13].

Запуск тестов локально:
```bash
dotnet test
```

## Руководство пользователя

1. **Выбор напитка:** кликните по экрану заставки, затем выберите карточку напитка в меню[cite: 7, 8].
2. **Настройка:** выберите объём, крепость, количество сахара, сиропы и топпинги, после чего нажмите **«Оплатить»**[cite: 7].
3. **Оплата:** выберите **«Оплатить картой»** или внесите купюры (`+50`, `+100`, `+500`) и нажмите **«Готово»**[cite: 7].
4. **Получение заказа:** дождитесь заполнения стакана в шахте выдачи, нажмите на него, чтобы забрать напиток, и кликните по блоку **«СДАЧА»** при оплате наличными[cite: 7, 8].
5. **Администрирование:** нажмите **«⚙ Настройки»** в левом нижнем углу автомата и введите пароль `admin` для пополнения запасов или редактирования ассортимента[cite: 7, 8].
